# Apex One beta is live

Apex One is now available as the central launch point for Apex MCC digital services.

The beta includes quick access to ApexID, system status, and upcoming Apex Development services. Blog posts in this folder are loaded into the Latest Updates section on the homepage, and each Read More link opens the full post.

## What's included

- Centralized Apex service cards
- Live system status messaging
- Blog cards loaded from `blogs/posts.json`
- Full post rendering from Markdown files in `blogs/`

More updates will be published here as new Apex services move closer to launch.
